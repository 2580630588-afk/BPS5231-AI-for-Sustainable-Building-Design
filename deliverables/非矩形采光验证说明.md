# 非矩形采光独立验证

## 试验范围与计算方法

本轮为看到此前研究结果后制定的补充试验。模拟运行前固定了全部案例、冷却需求预测、筛选阈值和比较规则。新增数据不参与训练、调参或模型选择。

宽翼L形、等边三角形、正五边形、正六边形与24边形近似圆形均采用850 m²、30°，窗墙比为20%和40%。每种条件比较三种玻璃×两种挑檐，共10个独立条件、60个主试验。另60次2 m网格模拟是测点敏感性复核，不应算作新增独立设计样本。项目累计2,040次年度模拟。

主试验使用4 m方格裁剪至真实平面轮廓，每个裁剪单元布置一个0.8 m高测点，以单元实际面积作为权重。若凹单元的合并重心在建筑外，则采用该单元最大三角裁剪片的重心。保留所有单元，权重之和为1。复核网格为2 m。

初始重心布点触发EnergyPlus距窗面小于0.15 m的计算限制，因此在正式修正版模拟前统一增加0.20 m安全距离。对不满足距离的点，采用0.025 m径向步长、2.5°方向间隔的确定性搜索移动至最近可用位置，保留原单元面积权重。原方案、报错和预测保存于revisions；没有按性能结果挑选案例或调整阈值。

每个测点统计2006非闰年日历中工作日、小时结束时刻10:00—18:00，共2,340小时内照度≥300 lux的时间百分比；再按面积权重求平均。这个平均DA300不是达到标准的面积百分比，也不是sDA、眩光或法规合规评价。

可行性定义为上述加权DA300≥50%。模型和简单规则共用模拟得到的可行性：模型在可行方案中选择预测冷却需求最低者；规则选择SHGC最低者，同值时优先较深挑檐，再按产品名称排序。实际最优使用同一可行集合中的模拟冷却需求。

## 网格复核与适用限制

4 m与2 m网格的平均绝对DA300差异为0.274个百分点，最大1.821个百分点。60个配对方案中有0个改变可行性；10个条件中有0个改变实际最优选项。最大冷却需求差异为0.000000 kWh热/(m²·年)。

网格复核只能检查测点离散化敏感性，不能证明SplitFlux物理准确，也不能代表Radiance或实测验证。L形的直接遮挡由EnergyPlus模型处理，反射光仍采用简化计算；未建模家具、内部隔断与眩光。

全部新增条件仅覆盖850 m²与30°，不能据此声明任意面积、朝向或非规则多边形均可使用综合选型。

模型唯一优于规则的条件是等边三角形、20%窗墙比：模型选择SN70/35与0.6 m挑檐，规则选择SN40/23且无挑檐；前者的模拟冷却需求低0.208 kWh热/(m²·年)。这是一个范围明确的小优势，不能外推为模型普遍优于规则。预测还可用于量化冷却收益和采光约束的代价。

全部120次模拟完成8,760小时，无严重错误。警告分类保留于summary.json：{"CheckUsedConstructions: There are 15 nominally unused constructions in input.": 120, "No Glare Calculation Daylighting Reference Point Name provided for object named: DAYLIGHT": 120, "GetDaylightingControls: Fraction of zone or space controlled by the Daylighting reference points is < 1.0.": 120}。不开启眩光计算与采光调光是本次设定，不代表相应性能已满足要求。

## 可复现文件

- `data/nonrect_daylight/protocol.json`：冻结的设计与哈希。
- `data/nonrect_daylight/sensor_points.csv`：测点坐标、代表面积和权重。
- `data/nonrect_daylight/frozen_predictions.csv`：运行模拟之前冻结的预测。
- `results/nonrect_daylight/simulation_results.csv`：120次结果。
- `results/nonrect_daylight/decisions.csv`：主试验及加密网格选型。
- `results/nonrect_daylight/grid_comparison.csv`：60对网格对照。
- `results/nonrect_daylight/runs/`：每次模拟的记录、警告和逐点DA300。

从项目根目录运行：`python scripts/nonrect_daylight.py analyze`。重新模拟使用：`python scripts/nonrect_daylight.py run --energyplus "EnergyPlus 24.2的完整路径"`。原始研究与此前30次补充模拟保留在各自目录。

方法依据：[EnergyPlus 24.2 Daylighting](https://bigladdersoftware.com/epx/docs/24-2/input-output-reference/group-daylighting.html)。
